# Sophandros

The website for Sophandros, a classical education for the modern professional: www.sophandros.com.

The site is plain HTML, generated by one small Python script with no dependencies.

## How it fits together

| Path | What it holds |
| --- | --- |
| `content/curriculum.py` | **The single source of truth.** Every part, chapter, reading, tool, exercise and edition. Edit this to change the course; every page updates. |
| `content/chapters/<slug>.html` | The full text of a written chapter. A chapter with a file here and `"status": "written"` in `curriculum.py` shows as *Ready to read*. |
| `static/` | Copied as-is: the stylesheet (`css/site.css`), fonts, logos, images, favicons and `CNAME`. |
| `build.py` | Builds every page into `dist/`. |

## Build and preview

```
python3 build.py           # writes dist/
python3 build.py --serve   # builds, then serves at http://localhost:8000
```

## Publish

Push to `main`. The GitHub Action in `.github/workflows/deploy.yml` runs `python3 build.py` and publishes `dist/` to GitHub Pages at the custom domain in `static/CNAME`. In the repository settings, Pages must be set to **Source: GitHub Actions**.

## Adding a chapter

1. Write the chapter body as HTML in `content/chapters/<slug>.html` (copy the structure of `01-the-self.html`).
2. In `content/curriculum.py`, set that chapter's `"status"` to `"written"`.
3. Build, check, push.
